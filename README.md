# Statistical Inference Project

## Overview
This project was completed and presented for the Mathematics course "Statistical Inference." The work is split into two main parts: a code and report component, and a presentation component. The analysis focuses on drawing meaningful conclusions from the "Wholesale customers data" dataset using statistical inference techniques.

## Repository Structure and Contents

### Part 1: Code and Report
*   **`Statistical Inference Project Code.ipynb`**: A Jupyter Notebook containing the complete analysis code, including data exploration, statistical tests, and model building.
*   **`Statistical Inference Project Report.pdf`**: The final written report detailing the methodology, results, and conclusions of the analysis.

### Part 2: Presentation
*   **`Beige and Orange Illustrative Food Market Presentation.pdf`**: The slide deck used for the project presentation, summarizing the key questions, methods, and findings.

### Dataset
*   **`Wholesale customers data.csv`**: The dataset used for the analysis, containing information about wholesale customers.

## Key Statistical Methods and Techniques
*   **Statistical Inference**: Applying principles of estimation and hypothesis testing to draw conclusions from data.
*   **Data Exploration**: Initial analysis to understand distributions, relationships, and patterns.
*   **Hypothesis Testing**: Formulating and testing statistical hypotheses to answer research questions.
*   **Modeling**: Potentially using regression or other statistical models to quantify relationships.
*   **Results Communication**: Translating complex statistical findings into clear reports and presentations.
